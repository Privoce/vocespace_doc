# History

The History module is used to view space usage history and participant duration rankings.

![History](/features/history.png)

## Space Usage History

A table displays the historical usage of all spaces:

| Column | Description |
|--------|-------------|
| Space | Space ID |
| Historical Duration | Total accumulated usage duration since the space was created |
| Today's Duration | Usage duration for today |

Supports paginated browsing, and you can adjust the number of items displayed per page in the bottom right corner.

## Participant Rankings

Displays participant usage duration rankings for each space across daily, weekly, and monthly dimensions.

### Switch Rankings

Click "Daily", "Weekly", or "Monthly" tabs to switch between different time dimension rankings.

### View Different Spaces

Use the space dropdown selector to switch between different space rankings.

### Ranking Information

| Information | Description |
|-------------|-------------|
| Participant | User name |
| Historical Accumulated Duration | Total usage duration of the user in this space |
| Current Period Duration | Usage duration for the current day/week/month |

Rankings are sorted by "Current Period Duration" from highest to lowest.

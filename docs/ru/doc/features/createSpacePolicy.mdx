# Политика создания пространств

Политика создания пространств контролирует, какие пользователи имеют разрешение на создание новых пространств.

## Опции политики

| Политика | Значение | Описание |
|----------|----------|----------|
| Все пользователи | `all` | Любой пользователь может создавать новые пространства |
| Только аутентифицированные | `authenticated` | Только аутентифицированные пользователи могут создавать новые пространства |
| Режим белого списка | `whitelist` | Только пользователи из белого списка могут создавать новые пространства |
| Отключено | `none` | Отключить создание новых пространств |

## Способы конфигурации

### Через конфигурацию панели управления

1. Откройте панель глобальной конфигурации панели управления
2. Найдите опцию «Политика создания пространств»
3. Выберите нужную политику
4. Конфигурация вступает в силу немедленно, без перезапуска сервера

### Через файл конфигурации

Настройте в `vocespace.conf.json`:

```json
{
  "create_space": "all"
}
```

## Режим белого списка

При выборе режима белого списка вам также необходимо настроить список пользователей, которым разрешено создавать пространства:

```json
{
  "create_space": "whitelist",
  "whiteList": ["USER-han", "USER-EE", "USER-99"]
}
```

В панели управления вы можете вводить идентификаторы пользователей построчно в текстовом поле белого списка.

## Быстрое переключение

В меню действий на главной странице панели управления вы можете быстро переключать политику создания пространств, не открывая полную панель глобальной конфигурации.

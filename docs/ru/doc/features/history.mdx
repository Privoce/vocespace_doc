# История

Модуль «История» используется для просмотра истории использования пространств и рейтинга продолжительности участников.

![История](/features/history.png)

## История использования пространств

Таблица отображает историческое использование всех пространств:

| Столбец | Описание |
|---------|----------|
| Пространство | ID пространства |
| Историческая продолжительность | Общая накопленная продолжительность использования с момента создания пространства |
| Сегодняшняя продолжительность | Продолжительность использования за сегодня |

Поддерживает постраничный просмотр, вы можете настроить количество элементов на странице в правом нижнем углу.

## Рейтинг участников

Отображает рейтинг продолжительности использования участников для каждого пространства по дням, неделям и месяцам.

### Переключение рейтинга

Нажмите вкладки «День», «Неделя» или «Месяц» для переключения между различными временными измерениями рейтинга.

### Просмотр разных пространств

Используйте выпадающий список пространств для переключения между рейтингами разных пространств.

### Информация рейтинга

| Информация | Описание |
|------------|----------|
| Участник | Имя пользователя |
| Историческая накопленная продолжительность | Общая продолжительность использования пользователя в этом пространстве |
| Продолжительность за период | Продолжительность использования за текущий день/неделю/месяц |

Рейтинг сортируется по «Продолжительности за период» от наибольшей к наименьшей.

# Управление записями

Модуль «Управление записями» используется для поиска и управления файлами записей комнат.

![Управление записями](/features/recording.png)

## Поиск файлов записей

1. Введите имя комнаты в поле поиска
2. Нажмите кнопку «Поиск»
3. Система ищет файлы записей комнаты в хранилище S3

## Список файлов записей

После успешного поиска отображается список файлов записей:

| Столбец | Описание |
|---------|----------|
| Имя файла | Название файла записи |
| Размер | Размер файла |
| Время создания | Время начала записи |

## Действия

| Действие | Описание |
|----------|----------|
| Скачать | Нажмите для создания ссылки на скачивание, действительной в течение 3 дней |
| Удалить | Нажмите для永久ного удаления файла записи из S3 |

## Статус подключения

Статус подключения к S3 отображается в верхней части страницы:
- **Подключено**: Сервис S3 работает нормально, функции управления записями полностью функциональны
- **Не подключено**: Сервис S3 недоступен, проверьте конфигурацию

## Конфигурация S3

Файлы записей хранятся в Amazon S3. Вам необходимо настроить информацию сервиса S3 в `vocespace.conf.json`:

```json
{
  "s3": {
    "accessKey": "your-access-key",
    "secretKey": "your-secret-key",
    "bucket": "your-bucket",
    "region": "your-region"
  }
}
```

| Поле | Описание |
|------|----------|
| accessKey | AWS Access Key ID |
| secretKey | AWS Secret Access Key |
| bucket | Имя S3 бакета |
| region | Регион AWS (например, us-east-2) |

## Как настроить S3 в консоли AWS

### 1. Создание пользователя IAM

- Войдите в консоль AWS и перейдите в сервис IAM
- Выберите «Пользователи» в левом меню и нажмите «Создать пользователя»
- Введите имя пользователя, отметьте «Предоставить доступ к консоли AWS и программный доступ», затем нажмите «Далее»
- Выберите «Прикрепить политики напрямую», найдите и отметьте `AmazonS3FullAccess` (или создайте пользовательскую политику для ограничения разрешений)
- После создания получите «Access Key ID» и «Secret Access Key» на странице сведений о пользователе

### 2. Создание S3 бакета

- Перейдите в сервис S3 и нажмите «Создать бакет»
- Введите имя бакета и выберите регион
- Снимите отметку «Блокировать все общедоступные доступа», если необходимо
- Нажмите «Создать»

### 3. Заполнение файла конфигурации

Введите полученные accessKey, secretKey, имя бакета и регион в конфигурацию s3 в `vocespace.conf.json`.

> **Примечание**: Храните свои учётные данные в безопасности и не передавайте их в общедоступные репозитории кода.

## Автоматическая очистка

После сохранения файлов записей в S3 система автоматически создаёт задачу очистки через 7 дней. Файлы будут автоматически удалены через 7 дней, чтобы избежать постоянного роста расходов на хранение.

# Управление пространствами

Модуль «Управление пространствами» используется для единого управления всеми пространствами.

![Управление пространствами](/features/manageSpace.png)

## Аутентификация

**При первом использовании необходимо ввести Host Token для аутентификации**. После успешной проверки повторный ввод не требуется в течение 1 часа.

Host Token — это учётные данные для аутентификации администратора, назначаемые системным администратором. Вы должны ввести правильный Token перед выполнением операций управления.

## Функции управления пространствами

### 1. Поиск пространств

Введите имя пространства в поле поиска для быстрого поиска целевого пространства.

### 2. Просмотр сведений о пространстве

Нажмите на карточку пространства для просмотра:
- Название пространства
- Список подкомнат и участников в каждой комнате
- Список участников, находящихся онлайн в данный момент
- Текущий владелец комнаты

### 3. Удаление пространства

- Нажмите кнопку удаления на карточке пространства
- Подтвердите для永久ного удаления пространства и всех его данных
- Эта операция необратима, пожалуйста, действуйте с осторожностью

> **Примечание**: Удаление пространства очищает все данные этого пространства, включая конфигурацию комнаты, записи чатов, исторические данные и т.д.

### 4. Передача владельца комнаты

- Нажмите кнопку «Редактировать владельца» на карточке пространства
- Выберите нового владельца комнаты из списка участников, находящихся онлайн в данный момент
- Нажмите «Сохранить» для завершения передачи

### 5. Экспорт пространства

- Нажмите кнопку экспорта на карточке пространства
- Система генерирует файл Markdown и автоматически загружает его
- Экспортируемый контент включает:
  - Название пространства
  - Подкомнаты и участников
  - Записи доступа пользователей

### 6. Выход

Нажмите кнопку «Выход» для очистки статуса проверки Host Token. Вам потребуется повторно ввести Token для следующей операции.

## Конфигурация Host Token

Host Token настраивается в `vocespace.conf.json`:

```json
{
  "hostToken": "your-host-token"
}
```

## Часто задаваемые вопросы

### Как долго действительна проверка Token?

Проверка действительна в течение 1 часа после успешной аутентификации. В течение этого периода повторный ввод не требуется. Через 1 час необходимо пройти повторную проверку.

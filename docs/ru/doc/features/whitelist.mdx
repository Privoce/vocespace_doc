# Режим белого списка

Режим белого списка используется для ограничения того, какие пользователи могут создавать новые пространства.

![Белый список](/features/whitelist.png)

## Настройка белого списка

### 1. Установка политики создания пространств

В глобальной конфигурации панели управления установите политику создания пространств в «Режим белого списка» (`whitelist`).

### 2. Добавление пользователей в белый список

Введите разрешённые идентификаторы пользователей построчно в текстовом поле белого списка, например:

```
USER-han
USER-EE
USER-99
```

### 3. Сохранение конфигурации

Изменения конфигурации вступают в силу немедленно, без перезапуска сервера.

## Пример конфигурации белого списка

В `vocespace.conf.json` конфигурация белого списка выглядит следующим образом:

```json
{
  "create_space": "whitelist",
  "whiteList": ["USER-han", "USER-EE", "USER-99"]
}
```

| Поле | Описание |
|------|----------|
| create_space | Политика создания пространств, установите `whitelist` для включения режима белого списка |
| whiteList | Массив идентификаторов пользователей, которым разрешено создавать пространства |

## Опции политики создания пространств

| Политика | Значение | Описание |
|----------|----------|----------|
| Все пользователи | `all` | Любой пользователь может создавать новые пространства |
| Только аутентифицированные | `authenticated` | Только аутентифицированные пользователи могут создавать новые пространства |
| Режим белого списка | `whitelist` | Только пользователи из белого списка могут создавать новые пространства |
| Отключено | `none` | Отключить создание новых пространств |

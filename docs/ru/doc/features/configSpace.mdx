# Глобальная конфигурация

Панель глобальной конфигурации используется для управления системными настройками VoceSpace.

![Глобальная конфигурация](/features/configSpace.png)

## Доступ к глобальной конфигурации

В меню действий на главной странице панели управления нажмите «Глобальная конфигурация», чтобы открыть панель конфигурации.

## Элементы конфигурации

### Аудио/Видео конфигурация

| Настройка | Описание | Варианты |
|-----------|----------|----------|
| Кодек | Выберите формат видеокодирования | `vp9` / `vp8` / `h264` / `av1` |
| Разрешение | Установите разрешение видео | `720p` / `1080p` / `4k` |
| Макс. битрейт | Ограничение максимального битрейта видео, влияющее на качество и пропускную способность | Числовое значение, например `3000000` |
| Макс. частота кадров | Установите максимальную частоту кадров видео | Числовое значение, например `30` |
| Приоритет | Приоритет передачи при перегрузке сети | `high` / `medium` / `low` |

Пример конфигурации:
```json
{
  "codec": "vp9",
  "resolution": "1080p",
  "maxBitrate": 3000000,
  "maxFramerate": 30,
  "priority": "high"
}
```

### Конфигурация TURN-сервера

| Настройка | Описание |
|-----------|----------|
| URLs | Массив адресов TURN-сервера |
| Имя пользователя | Имя пользователя для аутентификации TURN-сервера |
| Пароль | Пароль для аутентификации TURN-сервера |

Пример конфигурации:
```json
{
  "livekit": {
    "turn": {
      "urls": ["turn:your-turn-server.com:3478"],
      "username": "your-username",
      "credential": "your-password"
    }
  }
}
```

> TURN-серверы используются для установления P2P-соединений в условиях NAT/брандмауэра.

### Конфигурация ИИ

| Настройка | Описание | Пример значения |
|-----------|----------|-----------------|
| Включено | Включить функции ИИ | `true` / `false` |
| API Key | Ключ доступа к сервису ИИ | `xxxx` |
| API URL | URL интерфейса сервиса ИИ | `xxxx` |
| Модель | Название используемой модели ИИ | `qwen3-omni-flash` |
| Макс. токенов | Максимальная длина вывода для анализа ИИ | `4000` |

Пример конфигурации:
```json
{
  "ai": {
    "enabled": true,
    "apiKey": "xxxx",
    "apiUrl": "xxxx",
    "model": "qwen3-omni-flash",
    "maxTokens": 4000
  }
}
```

### Политика создания пространств

| Политика | Значение | Описание |
|----------|----------|----------|
| Все пользователи | `all` | Любой пользователь может создавать новые пространства |
| Только аутентифицированные | `authenticated` | Только аутентифицированные пользователи могут создавать новые пространства |
| Режим белого списка | `whitelist` | Только пользователи из белого списка могут создавать новые пространства |
| Отключено | `none` | Отключить создание новых пространств |

Пример конфигурации:
```json
{
  "create_space": "all"
}
```

Режим белого списка также требует настройки списка пользователей:
```json
{
  "create_space": "whitelist",
  "whiteList": ["USER-han", "USER-EE", "USER-99"]
}
```

## Полный пример конфигурации

```json
{
  "livekit": {
    "key": "your-api-key",
    "secret": "your-api-secret",
    "url": "wss://your.server.name",
    "turn": { "credential": "", "username": "", "urls": [] }
  },
  "codec": "vp9",
  "resolution": "1080p",
  "maxBitrate": 3000000,
  "maxFramerate": 30,
  "priority": "high",
  "redis": { "enabled": true, "host": "localhost", "port": 6379, "password": "vocespace", "db": 0 },
  "s3": {
    "accessKey": "your-access-key",
    "secretKey": "your-secret-key",
    "bucket": "your-bucket-name",
    "region": "us-east-2"
  },
  "serverUrl": "your.server.name",
  "hostToken": "your-host-token",
  "license": "your-license-token",
  "ai": {
    "enabled": true,
    "apiKey": "your-ai-api-key",
    "apiUrl": "your-ai-api-url",
    "model": "qwen3-omni-flash",
    "maxTokens": 4000
  },
  "create_space": "all",
  "whiteList": ["USER-han", "USER-EE", "USER-99"]
}
```

## Примечания

- Изменения конфигурации вступают в силу немедленно, без перезапуска сервера
- Храните свои учётные данные в безопасности и не передавайте их в общедоступные репозитории кода
- Рекомендуется создать резервную копию текущей конфигурации перед внесением изменений

# Главная

Главная — это основной вид панели управления, где вы можете просматривать состояние всех активных пространств и участников в реальном времени.

![Главная](/features/home.png)

## Карточки статистики

В верхней части страницы отображаются пять ключевых метрик:

| Метрика | Описание |
|---------|----------|
| Активные пространства | Количество пространств с пользователями, находящимися онлайн |
| Всего участников | Общее количество пользователей во всех пространствах |
| Участников онлайн | Количество пользователей, находящихся онлайн в данный момент |
| Аутентифицированных участников | Количество пользователей, вошедших через аутентификацию платформы |
| Активных записей | Количество пространств, в которых ведётся запись |

## Меню действий

Справа от карточек статистики находится выпадающее меню действий, предоставляющее следующие функции:

### Обновить данные

Вручную обновить всю статистику на странице. По умолчанию система автоматически обновляет данные каждые 2 минуты.

### Глобальная конфигурация

Откройте панель глобальной конфигурации для изменения следующих настроек:

#### Аудио/Видео конфигурация

| Настройка | Описание | Пример значения |
|-----------|----------|-----------------|
| Кодек | Выберите формат видеокодирования | `vp9` / `vp8` / `h264` / `av1` |
| Разрешение | Установите разрешение видео | `720p` / `1080p` / `4k` |
| Макс. битрейт | Ограничение максимального битрейта видео, влияющее на качество и пропускную способность | `3000000` |
| Макс. частота кадров | Установите максимальную частоту кадров видео | `30` |
| Приоритет | Приоритет передачи при перегрузке сети | `high` / `medium` / `low` |

#### Конфигурация TURN-сервера

| Настройка | Описание |
|-----------|----------|
| URLs | Массив адресов TURN-сервера |
| Имя пользователя | Имя пользователя для аутентификации TURN-сервера |
| Пароль | Пароль для аутентификации TURN-сервера |

> TURN-серверы используются для установления P2P-соединений в условиях NAT/брандмауэра.

#### Конфигурация ИИ

| Настройка | Описание | Пример значения |
|-----------|----------|-----------------|
| Включено | Включить функции ИИ | `true` / `false` |
| API Key | Ключ доступа к сервису ИИ | `xxxx` |
| API URL | URL интерфейса сервиса ИИ | `xxxx` |
| Модель | Название используемой модели ИИ | `qwen3-omni-flash` |
| Макс. токенов | Максимальная длина вывода для анализа ИИ | `4000` |

#### Политика создания пространств

| Политика | Описание |
|----------|----------|
| Все пользователи | Любой пользователь может создавать новые пространства (`all`) |
| Только аутентифицированные | Только аутентифицированные пользователи могут создавать новые пространства (`authenticated`) |
| Режим белого списка | Только пользователи из белого списка могут создавать новые пространства (`whitelist`) |
| Отключено | Отключить создание новых пространств (`none`) |

> В режиме белого списка вы можете вводить разрешённые идентификаторы пользователей построчно в текстовом поле, например:
> ```
> USER-han
> USER-EE
> USER-99
> ```

Изменения конфигурации вступают в силу немедленно, без перезапуска сервера.

### Очистка базы данных

Очистить все данные в базе данных Redis.

> **Предупреждение**: Эта операция удалит все данные пространств, записи чатов, состояния пользователей и т.д. Пожалуйста, подтвердите перед выполнением.

Шаги:
1. Введите Host Token для подтверждения личности
2. Нажмите кнопку подтверждения
3. Система автоматически обновит данные страницы после очистки

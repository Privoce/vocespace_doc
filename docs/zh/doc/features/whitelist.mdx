# 白名单模式

白名单模式用于限制哪些用户可以创建新空间。

![白名单](/features/whitelist.png)

## 配置白名单

### 1. 设置创建空间策略

在 Dashboard 的全局配置中，将创建空间策略设置为"白名单模式"（`whitelist`）。

### 2. 添加白名单用户

在白名单文本框中逐行输入允许创建空间的用户 ID，例如：

```
USER-han
USER-EE
USER-99
```

### 3. 保存配置

配置修改后立即生效，无需重启服务器。

## 白名单配置示例

在 `vocespace.conf.json` 中，白名单配置如下：

```json
{
  "create_space": "whitelist",
  "whiteList": ["USER-han", "USER-EE", "USER-99"]
}
```

| 字段 | 说明 |
|------|------|
| create_space | 创建空间策略，设置为 `whitelist` 启用白名单模式 |
| whiteList | 允许创建空间的用户 ID 数组 |

## 创建空间策略选项

| 策略 | 值 | 说明 |
|------|-----|------|
| 所有人可创建 | `all` | 任何用户都可以创建新空间 |
| 仅认证用户 | `authenticated` | 只有认证用户才能创建新空间 |
| 白名单模式 | `whitelist` | 只有白名单中的用户才能创建新空间 |
| 禁止创建 | `none` | 关闭新空间创建功能 |

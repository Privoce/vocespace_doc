# 日志监控

日志监控模块用于查看系统心跳日志和清理记录。

![日志监控](/features/log.png)

## 实时日志

显示系统心跳检测的实时日志：

| 颜色 | 含义 |
|------|------|
| 红色文字 | 错误信息，表示出现了严重问题 |
| 橙色文字 | 警告信息，表示可能存在异常 |
| 白色文字 | 正常信息，表示系统运行正常 |

日志每 3 秒自动刷新，显示最新的检测记录。

## 今日清理记录

表格展示今天系统自动清理的记录：

| 列名 | 说明 |
|------|------|
| 清理时间 | 执行清理操作的时间 |
| 清理的房间 | 被清理的房间名称 |
| 清理用户数 | 该房间中被清理的用户数量 |
| 清理策略 | 清理原因 |

### 清理策略说明

| 策略 | 说明 |
|------|------|
| 幽灵房间 | 房间在 LiveKit 中已不存在，但 Redis 中仍有数据 |
| 有 Redis 无 LiveKit | 用户在 Redis 中存在但 LiveKit 中已离线 |

支持分页查看，可在右下角调整每页显示的条数。

## 常见问题

### 日志中的"幽灵用户"是什么？

当用户退出房间后，由于网络或其他原因，Redis 中可能仍保留该用户的数据。系统每 5 分钟执行一次心跳检测，自动清理这些残留数据，保证数据一致性。

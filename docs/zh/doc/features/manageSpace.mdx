# 管理空间

管理空间模块用于对所有空间进行统一管理。

![管理空间](/features/manageSpace.png)

## 身份验证

**首次使用需要输入 Host Token 进行身份验证**，验证成功后 1 小时内无需重复输入。

Host Token 是管理员身份验证凭证，由系统管理员分配。输入正确的 Token 后才能执行管理操作。

## 空间管理功能

### 1. 搜索空间

在搜索框中输入空间名称，快速定位目标空间。

### 2. 查看空间详情

点击空间卡片可以查看：
- 空间名称
- 子房间列表及每个房间的参与者
- 当前在线的参与者列表
- 当前房主

### 3. 删除空间

- 点击空间卡片上的删除按钮
- 确认后永久删除该空间及其所有数据
- 此操作不可恢复，请谨慎操作

> **注意**：删除空间会清除该空间的所有数据，包括房间配置、聊天记录、历史数据等。

### 4. 转移房主

- 点击空间卡片上的"编辑房主"按钮
- 从当前在线的参与者列表中选择新的房主
- 点击保存完成转移

### 5. 导出空间

- 点击空间卡片上的导出按钮
- 系统会生成一个 Markdown 文件并自动下载
- 导出内容包括：
  - 空间名称
  - 子房间及参与者
  - 用户访问记录

### 6. 退出登录

点击"退出"按钮清除 Host Token 验证状态，下次操作需要重新输入 Token。

## Host Token 配置

Host Token 在 `vocespace.conf.json` 中配置：

```json
{
  "hostToken": "your.hostToken"
}
```

## 常见问题

### Token 验证有效期是多久？

验证成功后 1 小时内有效，期间无需重复输入。1 小时后需要重新验证。

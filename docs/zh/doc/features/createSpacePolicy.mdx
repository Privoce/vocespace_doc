# 创建空间策略

创建空间策略用于控制哪些用户有权限创建新空间。

## 策略选项

| 策略 | 配置值 | 说明 |
|------|--------|------|
| 所有人可创建 | `all` | 任何用户都可以创建新空间 |
| 仅认证用户 | `authenticated` | 只有认证用户才能创建新空间 |
| 白名单模式 | `whitelist` | 只有白名单中的用户才能创建新空间 |
| 禁止创建 | `none` | 关闭新空间创建功能 |

## 配置方式

### 通过 Dashboard 配置

1. 打开 Dashboard 的全局配置面板
2. 找到"创建空间策略"选项
3. 选择需要的策略
4. 配置立即生效，无需重启服务器

### 通过配置文件

在 `vocespace.conf.json` 中配置：

```json
{
  "create_space": "all"
}
```

## 白名单模式

当选择白名单模式时，还需要配置允许创建空间的用户列表：

```json
{
  "create_space": "whitelist",
  "whiteList": ["USER-han", "USER-EE", "USER-99"]
}
```

在 Dashboard 中，可以在白名单文本框中逐行输入用户 ID。

## 快速切换

在 Dashboard 首页的操作菜单中，可以快速切换创建空间策略，无需打开完整的全局配置面板。

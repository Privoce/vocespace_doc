# 历史记录

历史记录模块用于查看空间使用历史和参与者时长排行榜。

![历史记录](/features/history.png)

## 空间使用历史

表格展示所有空间的历史使用情况：

| 列名 | 说明 |
|------|------|
| 空间 | 空间 ID |
| 历史时长 | 该空间从创建至今的累计使用时长 |
| 今日时长 | 该空间今天的使用时长 |

支持分页浏览，可在右下角调整每页显示的条数。

## 参与者排行榜

按日/周/月三个维度展示每个空间中参与者的使用时长排名。

### 切换榜单

点击"日榜"、"周榜"、"月榜"标签切换不同时间维度的排行榜。

### 查看不同空间

使用空间下拉选择器切换不同空间的排行榜。

### 榜单信息

| 信息 | 说明 |
|------|------|
| 参与者 | 用户名称 |
| 历史累计时长 | 该用户在该空间的总使用时长 |
| 本期时长 | 当日/周/月的使用时长 |

榜单按"本期时长"从高到低排序。

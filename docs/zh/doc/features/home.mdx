# 首页

首页是 Dashboard 的核心视图，您可以实时查看所有活跃空间和参与者的状态。

![首页](/features/home.png)

## 统计卡片

页面顶部显示五个关键指标：

| 指标 | 说明 |
|------|------|
| 活跃空间 | 当前有用户在线的空间数量 |
| 总参与人数 | 所有空间中的用户总数 |
| 在线参与人数 | 当前在线的用户数量 |
| 已认证参与人数 | 通过平台认证登录的用户数量 |
| 活跃录制 | 正在进行录制的空间数量 |

## 操作菜单

统计卡片右侧有一个操作下拉菜单，提供以下功能：

### 刷新数据

手动刷新页面上的所有统计数据。系统默认每 2 分钟自动刷新一次。

### 全局配置

打开全局配置面板，可以修改以下设置：

#### 音视频配置

| 配置项 | 说明 | 示例值 |
|--------|------|--------|
| 编解码器 | 选择视频编码格式 | `vp9` / `vp8` / `h264` / `av1` |
| 分辨率 | 设置视频分辨率 | `720p` / `1080p` / `4k` |
| 最大码率 | 限制视频最大比特率，影响画质和带宽 | `3000000` |
| 最大帧率 | 设置视频最大帧率 | `30` |
| 优先级 | 网络拥塞时的传输优先级 | `high` / `medium` / `low` |

#### TURN 服务器配置

| 配置项 | 说明 |
|--------|------|
| URLs | TURN 服务器地址数组 |
| 用户名 | TURN 服务器认证用户名 |
| 密码 | TURN 服务器认证密码 |

> TURN 服务器用于在 NAT/防火墙环境下建立 P2P 连接。

#### AI 配置

| 配置项 | 说明 | 示例值 |
|--------|------|--------|
| 启用 | 是否启用 AI 功能 | `true` / `false` |
| API Key | AI 服务的访问密钥 | `xxxx` |
| API URL | AI 服务的接口地址 | `xxxx` |
| 模型 | 使用的 AI 模型名称 | `qwen3-omni-flash` |
| 最大 Token 数 | AI 分析的最大输出长度 | `4000` |

#### 创建空间策略

| 策略 | 说明 |
|------|------|
| 所有人可创建 | 任何用户都可以创建新空间 (`all`) |
| 仅认证用户 | 只有认证用户才能创建新空间 (`authenticated`) |
| 白名单模式 | 只有白名单中的用户才能创建新空间 (`whitelist`) |
| 禁止创建 | 关闭新空间创建功能 (`none`) |

> 白名单模式下，可以在文本框中逐行输入允许创建空间的用户 ID，例如：
> ```
> USER-han
> USER-EE
> USER-99
> ```

配置修改后立即生效，无需重启服务器。

### 数据库清理

清理 Redis 数据库中的所有数据。

> **警告**：此操作会清除所有空间数据、聊天记录、用户状态等，执行前请确认。

操作步骤：
1. 输入 Host Token 验证身份
2. 点击确认按钮
3. 系统执行清理后自动刷新页面数据
